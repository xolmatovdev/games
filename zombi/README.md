# 🧟 Zombi Qasoskori: Apocalypse Survival

**Zombi Qasoskori** — yuqori darajadagi dinamik 2D action/survival o'yini. Zamonaviy HTML5 Canvas, Web Audio API va chiroyli vizual effektlar (dinamik chiroq nuri, qon izlari, portlashlar, lazer nishoni, animatsiyalar) asosida yaratilgan.

---

## 🚀 O'yinni Ishga Tushirish

O'yinni ishga tushirish uchun quyidagi usullardan birini tanlang:

1. **Eng oson usul:** Papkadagi `Oyinni_Boshlash.bat` fayliga 2 marta bosing. O'yin avtomatik ravishda kompyuteringizdagi asosiy brauzerda (Chrome, Edge, Opera, Firefox) ochiladi.
2. **Yoki:** `index.html` faylini istalgan brauzer orqali to'g'ridan-to'g'ri oching.
3. **Python orqali:** Terminalda `python server.py` buyrug'ini kiriting.

## 🎮 Boshqaruv Tugmalari

| Tugma | Vazifasi |
| :--- | :--- |
| **W, A, S, D** yoki **Yo'nalish tugmalari** | Qahramonni harakatlantirish |
| **Sichqoncha (Cursor)** | Nishonga olish (360 daraja) |
| **Sichqonchaning chap tugmasi (LMB)** | O'q otish (uzluksiz bosib tursa avtomatik otadi) |
| **Sichqonchaning o'ng tugmasi (RMB)** yoki **G** | Portlovchi granata uloqtirish |
| **Space (Bo'shliq)** yoki **Shift** | Tezkor sakrash / Dash (xavfdan qochish) |
| **R** | Qurol o'qlarini yangilash (Reload) |
| **1, 2, 3, 4, 5** yoki **Sichqoncha g'ildiragi** | Qurollarni almashtirish |
| **P** yoki **ESC** | O'yinni vaqtincha to'xtatish (Pauza) |

## 🔫 Qurollar Arsenali

1. **Glock-18 (Pistol)**: Cheksiz zaxira o'qlari, aniq va ishonchli boshlang'ich qurol.
2. **SPAS-12 (Shotgun)**: Bir otishda 8 ta kartechka sochadi, yaqin masofadagi to'dalarni yo'q qilish uchun ideal.
3. **M4A1 Carbine (Avtomat)**: Yuqori tezlikda otuvchi, o'qlari dushmanni teshib o'tuvchi miltiq.
4. **Plasma Cannon (Plazma zambarak)**: Qalin zombi saflarini kuydirib, teshib o'tuvchi energiya nuri.
5. **RPG-7 Rocket (Raketamyot)**: Kuchli portlash to'lqiniga ega raketalar, ulkan maydondagi barcha dushmanlarni yakson qiladi.
6. **F-1 Granatalari**: To'planib kelayotgan zombilar orasiga uloqtirilib, keng maydonda portlaydi.

## 🧟 Zombi Turlari va Xususiyatlari

- **Oddiy Zombi (Walker)**: Yashil chirigan teriga ega, sekin lekin to'da bo'lib xavfli.
- **Qonli Chopqir (Runner)**: Qizil qonli teriga ega, o'ta tez yuguradi va chaqqon hujum qiladi.
- **Zaharli Kislotachi (Spitter)**: Uzoq masofadan zaharli yashil kislota otadi.
- **Kamikadze (Exploder)**: Qahramonga yaqinlashganda o'zini portlatib yuboruvchi shishgan zombi.
- **Mutant Titan (Tank)**: Qalin zirhli, ulkan o'lchamdagi baquvvat mahluq.
- **Apokalipsis Jallodi (Boss)**: Har 5-to'lqinda paydo bo'ladigan, erni larzaga soluvchi zarba va ulkan kuchga ega dahshatli boss!

## ✨ Vizual va Audio Xususiyatlari

- **Dinamik Yoritish (Flashlight System)**: Qorong'u muhitda qahramonning fonar nuri sichqoncha yo'nalishi bo'ylab harakatlanadi.
- **Doimiy Qon va Portlash Izlari**: Urilgan zombilardan oqayotgan qon polga singib, o'yin davomida saqlanib qoladi.
- **Harakatlanuvchi Radar (Minimap)**: Yuqori o'ng burchakda atrofingizdagi dushmanlar va bonuslarni skanerlovchi radar.
- **Kombinatsiya Tizimi (Kill Streaks)**: Ketma-ket o'ldirishlar orqali Double Kill, Rampage, Unstoppable unvonlari va ko'paytirilgan ballar.
- **Perk Kuchaytirishlari**: Har bir to'lqin yakunlangach 3 xil kuchaytirishdan birini tanlash imkoniyati (Vampirizm, Katta zarar, Tezlik, Qo'shimcha zirh va boshqalar).
- **100% Offline Ovozlar**: Web Audio API orqali hech qanday tashqi fayllarsiz real vaqtda generatsiya qilinadigan ovozlar.
