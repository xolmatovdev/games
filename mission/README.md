# CYBER-CORE: MISSION NEXUS ⚡
> **Kiber-Yadro: Missiya Matritsasi** — Harakatli (Action), dinamik va missiya yaratuvchisiga ega mustaqil kiber-kosmik o'yin.

---

## 🎮 O'yin haqida (Game Concept)
Ushbu o'yinda personajlar **odam yoki odamsimon emas**. Siz kosmosning qadimiy raqamli bo'shlig'ida uyg'ongan bio-mexanik energetik yadro — **NEXUS-01 VORTEX CORE**ni boshqarasiz.

Sizga qarshi turuvchi dushmanlar:
* 🛸 **Tezkor Ninachi Dronlar (Light Skimmers)** — o'ta epchil va to'da bo'lib hujum qiluvchi kiber-mexanizmlar.
* 🛡️ **Zirhli Plazma Tanklar (Heavy Dreadnoughts)** — og'ir qurollangan 8 burchakli qamal platformalari.
* 🦠 **Bio-Bo'linuvchi Sharlar (Splitter Parasites)** — o'lgan paytda mayda agressiv parazitlarga bo'linuvchi tirik bio-mexanika.
* 🎯 **Lazerli Snayperlar (Laser Snipers)** — uzoq masofadan nishonga oluvchi uchburchak stels-dronlar.
* 💣 **Kamikadze Bombalar (Explosive Mines)** — sizga yaqinlashib o'zini portlatuvchi qizil sharlar.
* 👾 **TITAN MEXANOZAVR (Mega Astral Boss)** — aylanuvchi lazer qalqonlari va ko'p fazali hujumlarga ega gigant koinot dreadnoughti.

## ⌨️ Boshqaruv tugmalari (Controls)
| Tugma | Vazifasi |
| :--- | :--- |
| **W, A, S, D** yoki **Yo'nalish tugmalari** | Yadroning reaktiv harakati (Inertsiya va tezlanish) |
| **Sichqoncha (Mouse)** | Nishonga olish |
| **Sichqonchaning chap tugmasi (LMB)** | Tanlangan quroldan o't ochish |
| **Bo'shliq (Space)** yoki **Sichqonchaning o'ng tugmasi (RMB)** | **Turbo Dash:** Dushman o'qlaridan tezkor sirpanib qochish (daxlsizlik) |
| **Q** yoki **E** | **EMP To'lqin:** Ekrandagi barcha dushman o'qlarini yo'q qiladi va dushmanlarni 3 soniyaga muzlatadi |
| **R** | **Hyper Rail Beam:** To'plangan quvvat bilan ulkan qiruvchi nur taratadi |
| **P** yoki **Esc** | O'yinni to'xtatish (Pauza) |
| **🔊 / 🔇** | Sintetik kiberpank saundtrek va ovozlarni yoqish/o'chirish |
| **🇺🇿 / 🇬🇧** | O'zbekcha / Inglizcha tilini almashtirish |

## 🛠️ Missiya Yaratuvchisi (Mission Architect)
O'yinning asosiy ajralib turuvchi xususiyati — **o'z shaxsiy missiyalaringizni yaratish imkoniyati**:
* **Missiya nomini** belgilash
* **Maqsad turini tanlash:**
  1. *To'liq Qirish (Elimination)* — Dushman to'dasini yo'q qilish
  2. *Vaqt Bo'yicha Omon Qolish (Survival)* — Belgilangan vaqt dosh berish
  3. *Kvant Kristallari Yig'ish (Core Extraction)* — Xaritadagi yadrolarni topish va yutish
  4. *Generator Himoyasi (Base Defense)* — Markaziy energiya reaktorini saqlab qolish
  5. *Boss Ovlash (Boss Hunt)* — Gigant Mexanozavr bilan yakkama-yakka olishuv
* **Xarita sektori:** Kiber-Neon, Qizil Plazma Magmasi, Zaharli Tuman yoki Qorong'u Asteroid Bo'shlig'i
* **Dushman tarkibi:** Qaysi robot va bio-mexanizmlar jangga kirishini belgilash
* **Xavf anomaliyalari:** Meteor yomg'irlari, tortuvchi Qora Tuynuk singulyarligi
* **Missiya kodini eksport/import qilish:** Yaratgan operatsiyangiz kodini nusxalab do'stlaringizga yuborishingiz mumkin!
