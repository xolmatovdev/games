# VELOCITY 3D &bull; Minimalist 3D Car Game

Siz uchun maxsus ishlab chiqilgan yuqori tezlikdagi, cheksiz magistral va drift 3D avto o'yini.
Dizayni foydalanuvchi talabiga ko'ra **juda ko'p rang-barang bo'lmagan (minimalist, to'q monoxrom, zamonaviy grafit va metallik estetika)** uslubida yaratildi.

---

## 🚀 Qanday o'ynash / Ishga tushirish:
1. `index.html` faylini istalgan brauzerda (Chrome, Edge, Firefox, Opera, Safari) oching, yoki `start_game.bat` faylini ikki marta bosing.
2. Hech qanday qo'shimcha o'rnatish shart emas — o'yin 100% oflayn ishlaydi (`three.min.js` va Web Audio API o'rnatilgan).

---

## 🎮 Boshqaruv tugmalari (Klaviatura):
- **Tezlanish (Gaz):** `W` yoki `↑` (Yuqoriga strelka)
- **Rul (Chap / O'ng):** `A` / `D` yoki `←` / `→` (Chap / O'ng strelkalar)
- **Tormoz:** `S` yoki `↓` (Pastga strelka)
- **Drift / Sirpanish:** `SPACE` (Bo'sh joy tugmasi)
- **Nitro Tezlatgich (N2O):** `SHIFT`, `F` yoki `N`
- **Kamera burchaklari (Chase / Hood / Isometric):** `C` tugmasi
- **Pauza / Davom ettirish:** `P` yoki `ESC`

> **Sensorli ekranlar / Mobil qurilmalar:** Ekranda sensorli boshqaruv tugmalari (Chap, O'ng, Gaz, Tormoz, Drift, Nitro) avtomatik ishlaydi.

---

## ⚡ Qiziqarli mexanika va o'yin imkoniyatlari:
1. **Xavfli quvib o'tishlar (Near Miss):**
   - Boshqa mashinalar yoki yuk mashinalari yonidan yuqori tezlikda (100+ km/soat) yaqin masofadan keskin quvib o'tsangiz, katta qo'shimcha ochkolar beriladi va Nitro zaxirangiz to'ladi!
2. **Drift va Sirpanish:**
   - Burilish paytida `SPACE` tugmasini bosib tursangiz, mashina drift holatiga kiradi, g'ildiraklardan tutun chiqadi va drift koeffitsiyenti (x1.0 ... x4.0) oshib boradi.
3. **Nitro Tezlatgich:**
   - 320 km/soatgacha giper-tezlanish, kamera FOV effekti va orqa olov chiqishi bilan maksimal adrenalin.
4. **Haqiqiy Web Audio ovoz effektlari:**
   - Dvigatel aylanmalari (RPM) ovozi tezlikka qarab o'zgaradi.
   - G'ildiraklar sirpanishi (skid), Nitro gumburlashi, quvib o'tish shamoli va to'qnashuv effektlari.
   - Minimalist elektron fon ritmi (fon musiqasini yuqoridagi tugma orqali yoqish/o'chirish mumkin).
5. **Ob-havo rejimlari:**
   - `🌙 TUNGI OYDIN` (Tungi toza shahar)
   - `🌧️ YOMG'IR` (Yomg'irli shahar, nam aks etuvchi yo'l)
6. **Garaj / Mashina rangini tanlash:**
   - Qora Obsidian, To'q Grafit, Titanium Kumush, Oq Marvarid, Tungi Ko'k (hammasi sokin, hashamatli minimalist ranglar).
7. **Natijalar saqlanishi:**
   - Eng yaxshi rekord (High Score) avtomatik ravishda xotirada saqlanadi.
